# GraphQL demos

Four small demos. Each has a React Native app (Apollo Client) and a GraphQL API (Apollo Server, Sequelize, PostgreSQL).

| Demo | App | API | What it shows |
|---|---|---|---|
| `Bitcoins` | `BitcoinsApp` | `bitcoins-api` | A paged `bitcoins(offset, limit)` query and an `addCoin(symbol)` mutation |
| `Demo` | `GraphQLDemo` | `prompts-api` | The smallest setup: one `Prompt` model and a `prompt` query that returns a random one |
| `Movies` | `MoviesApp` | `movies-api` | `feed`, `categories` and `currentUser` queries; `signUp`, `signIn`, `addVote` and `removeVote` mutations; JWT login with `bcrypt` and `jsonwebtoken` |
| `Redit` | `ReditApp` | `redit-api` | A `posts` query, `addPost` and `editPost` mutations, and subscriptions over WebSocket (`graphql-postgres-subscriptions`) |

## Stack

- Apps: React Native 0.66.3, React 17.0.2, `@apollo/client` 3.5, React Navigation 6 (except `GraphQLDemo`)
- APIs: Node.js, `apollo-server` 3.5, GraphQL 16, Sequelize 6, `pg`

## Run an API

```sh
cd Movies/movies-api        # or any other *-api folder
npm install
# create the PostgreSQL database named in config/config.json, then run the migrations and seeders with sequelize-cli
npm start
```

Production settings read `DATABASE_URL`.

## Run an app

```sh
cd Movies/MoviesApp         # or any other app folder
npm install
npx react-native run-android   # or run-ios
```

Set `BASE_URL` in the app's `ApolloClient.js` to your API address (it is a local network address in the repo).

## Notes

- The signing secret in `Movies/movies-api/resolvers/utils.js` is a demo value. Do not reuse it.
- The `debug.keystore` files under the apps' `android/` folders are the default React Native debug keystores.
